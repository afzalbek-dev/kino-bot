# 🎬 Кино Бот (Kino Bot)

> **Telegram-бот поиска фильмов корпоративного уровня на Python и Aiogram 3 с асинхронным хранилищем SQLite, VIP-доступом, избранными коллекциями и аналитикой для администраторов.**

## Целевая аудитория и назначение

- **Целевая аудитория**: Telegram-сообщества, каналы о кино, медиа-кураторы, любители кинематографа и администраторы ботов.
- **Основная цель**: Предоставить мгновенный и интерактивный опыт поиска фильмов в Telegram, позволяя пользователям находить фильмы по кодам, искать по названию, жанру, стране и году выпуска, сохранять фильмы в избранное и получать доступ к эксклюзивным VIP-релизам.

---

## Ключевые возможности

1. **Поиск и просмотр фильмов**:
   - Мгновенный поиск по коду (например: `K001`, `#K001`, `/kino K001`).
   - Мульти-параметрический поиск по названию, жанру, стране и году выпуска с сортировкой по рейтингу IMDb.
   - Подборка Топ-5 фильмов и кнопка случайного фильма.
2. **Контроль доступа и VIP-подписка**:
   - Двухуровневый каталог: Бесплатный (Free) и Премиальный (VIP).
   - Ограничение просмотра VIP-фильмов для обычных пользователей с понятным предложением подписки.
   - Команда администратора для выдачи временного VIP-доступа.
3. **Избранное и личные коллекции**:
   - Сохранение фильмов в один клик через inline-кнопки (`⭐ В избранное`).
   - Специальное меню `/favorites` для просмотра личного списка сохраненных картин.
4. **Интерактивный пользовательский интерфейс в Telegram**:
   - Карточки фильмов в формате HTML с названием, годом, оценкой IMDb, жанром, страной и кратким описанием.
   - Inline-клавиатуры с мгновенными обработчиками callback-запросов.
5. **Сохранение данных в базе данных**:
   - Асинхронный движок SQLite (`aiosqlite`) с автоматической инициализацией и миграцией структуры таблиц.
   - Автоматическое наполнение каталога из стартового набора (`sample_data/movies.json`).
6. **Панель управления администратора**:
   - Команды `/admin` и `/stats` для просмотра статистики пользователей, VIP-подписчиков, количества фильмов и поисковых запросов в реальном времени.

## Архитектура и стек технологий

- **Фреймворк**: Aiogram 3.10+ (архитектура роутеров и диспетчера)
- **База данных**: SQLite через `aiosqlite` с асинхронным пулом соединений
- **Валидация**: Pydantic v2 и Pydantic-Settings
- **Тестирование**: Pytest и pytest-asyncio (18 модульных и интеграционных тестов)
- **Сборка**: Стандартный `pyproject.toml` с setuptools

```
kino-bot/
├── kino_bot/
│   ├── __init__.py
│   ├── access.py        # Проверка прав доступа Free и VIP
│   ├── bot.py           # Обработчики команд, клавиатуры и polling
│   ├── catalog.py       # Логика доменного каталога и поиска
│   ├── config.py        # Отказоустойчивый загрузчик настроек
│   ├── database.py      # Асинхронная БД SQLite: пользователи, избранное, статистика
│   ├── demo.py          # Загрузчик резервного каталога JSON
│   └── models.py        # Доменные модели (Movie, MovieAccess, UserProfile)

│   ├── test_access.py        # Тесты проверки VIP-доступа

│   ├── test_catalog.py       # Тесты поиска и сортировки каталога

├── .env.example

├── pyproject.toml
├── README.md

```

## Системные требования и конфигурация

### Требования
- Python 3.11+
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)

### Переменные окружения (`.env`)

| Переменная | Обязательно | По умолчанию | Описание |
| :--- | :---: | :--- | :--- |
| `BOT_TOKEN` | Да | `""` | Токен бота от BotFather |
| `DATABASE_URL` | Нет | `sqlite+aiosqlite:///./kino.sqlite3` | Строка подключения к БД SQLite |
| `ADMIN_IDS` | Нет | `""` | Список Telegram ID администраторов через запятую |
| `DEMO_MODE` | Нет | `true` | Резервный запуск на JSON данных |
| `LOG_LEVEL` | Нет | `INFO` | Уровень логирования (`DEBUG`, `INFO`, `WARNING`) |

## Установка и запуск

### Локальный запуск

```bash
# 1. Клонирование репозитория
git clone https://github.com/afzalbek-dev/kino-bot.git
cd kino-bot

# 2. Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# 3. Установка зависимостей
pip install -e ".[dev]"

# 4. Настройка окружения
cp .env.example .env
# Отредактируйте .env и укажите ваш BOT_TOKEN

# 5. Запуск бота
python -m kino_bot.bot
```

### Запуск через Docker

```bash
docker compose up -d --build
```

## Команды Telegram-бота

| Команда | Описание |
| :--- | :--- |
| `/start` | Главное меню с интерактивными кнопками |
| `/help` | Справка по командам и поиску |
| `/kino <код>` | Карточка фильма по коду (например: `/kino K001`) |
| `/search <текст>` | Поиск фильмов по названию, жанру, стране или году |
| `/top` | Топ-5 фильмов с наивысшим рейтингом IMDb |
| `/random` | Случайная рекомендация фильма |
| `/favorites` | Личный список сохраненных фильмов |
| `/vip` | Проверка текущего статуса VIP-подписки |
| `/admin` | Статистика и панель управления администратора |
| `/grant_vip <id> [дни]` | (Только админ) Выдача VIP-доступа пользователю |
